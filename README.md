# 基于 JavaWeb 的东北地方特色产品销售网站

本项目使用 Spring Boot 3、Thymeleaf、Spring Data JPA 和 H2 数据库实现。数据库文件首次启动后自动生成在 `data` 目录，不需要单独安装 MySQL。

## 运行环境

- JDK 17 或更高版本
- Maven 3.9 或更高版本

## 启动方法

1. 在本目录打开终端。
2. 执行 `mvn spring-boot:run`。
3. 浏览器访问 `http://localhost:8080`。

Windows 用户也可以双击 `启动网站.bat`。首次运行会联网下载 Maven 依赖。

## 演示账号

- 普通用户：`demo` / `demo123`
- 管理员：`admin` / `admin123`

## 已实现功能

- 商品首页、关键词及分类搜索、商品详情
- 注册、登录、退出和会话状态
- 购物车添加、修改数量、删除、金额计算
- 收货信息填写、订单提交、库存扣减、个人订单查询
- 后台商品新增与删除、订单状态更新、用户及运营数据查看
- H2 文件数据库持久化、响应式页面

## 生产部署说明

本项目用于毕业设计演示。正式部署时应增加密码哈希、CSRF 防护、参数校验、图片上传、支付平台沙箱、日志审计和数据库备份，并将 H2 替换为 MySQL 8。
